### Cracking Weak Hashing
Rainbow tables, cracking

#### SHA-1

```bash
curl -s -X POST http://localhost:8081/demo/signup_sha1 \
  -H 'content-type: application/json' \
  -d '{"email":"amy@example.com","password":"p@ssw0rd"}'

curl -s -X POST http://localhost:8081/demo/signup_sha1 \
  -H 'content-type: application/json' \
  -d '{"email":"ben@example.com","password":"p@ssw0rd"}'

curl -s http://localhost:8081/demo/dump_sha1 | jq .

```
Copy the sha1
```bash
HASH="57b2ad99044d337197c0c39fd3823568ff81e48a"
curl -s -X POST http://localhost:8081/demo/crack_sha1 \
  -H 'content-type: application/json' \
  -d '{"hash":"'"$HASH"'"}' | jq .

```
