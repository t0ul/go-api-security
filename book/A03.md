# A03 Injection

## Good

### Start secure api

```bash
go run ./cmd/api
# GOOD API on :8080
```

### Make two notes
```bash
curl -s -H "X-User: alice" -H 'content-type: application/json' \
  -d '{"title":"alice t","body":"alice b"}' http://localhost:8080/notes

curl -s -H "X-User: bob" -H 'content-type: application/json' \
  -d '{"title":"bob t","body":"bob b"}' http://localhost:8080/notes 

```

### Vulnerability doesn't work (kinda)
```bash
curl -s -H "X-User: alice' OR 1=1 -- " "http://localhost:8080/notes?q=test"
```


## BAD example

### Start the bad api
`go run ./cmd/badapi`

### Make two notes

```bash
# start BAD
go run ./cmd/badapi

# seed a couple notes
curl -s -H "X-User: alice" -H 'content-type: application/json' \
  -d '{"title":"alice t","body":"alice b"}' http://localhost:8081/notes

curl -s -H "X-User: bob" -H 'content-type: application/json' \
  -d '{"title":"bob t","body":"bob b"}' http://localhost:8081/notes



```

### Vulnerability

```bash
# inject via owner — NOTE the header quoting
curl -s -H "X-User: alice' OR 1=1 -- " "http://localhost:8081/notes?q=test"
# ❌ Returns BOTH Alice and Bob notes (leak)
```
