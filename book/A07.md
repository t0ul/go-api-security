# A07

## Good real login and use token

```bash
curl -s -X POST http://localhost:8080/demo/signup \
  -H 'content-type: application/json' \
  -d '{"email":"amy@example.com","password":"p@ssw0rd"}'

# get a JWT
TOK=$(curl -s -X POST http://localhost:8080/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"amy@example.com","password":"p@ssw0rd"}' | jq -r .token)
echo "$TOK"

# create note (JWT-protected)
curl -s -H "Authorization: Bearer $TOK" \
  -H 'content-type: application/json' \
  -d '{"title":"jwt note","body":"secure"}' \
  http://localhost:8080/notes | jq .

# search (owner-scoped by sub)
curl -s -H "Authorization: Bearer $TOK" \
  'http://localhost:8080/notes?q=jwt' | jq .
```

## Showing Good server Rejects Bad token

### 1. Bad unsigned token on good server

```bash
# get an unsigned alg:"none" token from the BAD server (:8081)
TOK_BAD=$(curl -s -X POST http://localhost:8081/auth/login_none \
  -H 'content-type: application/json' \
  -d '{"email":"admin@example.com"}' | jq -r .token)

# try to use it on the GOOD server (:8080) → rejected
curl -i -s -H "Authorization: Bearer $TOK_BAD" \
  http://localhost:8080/notes
```

### 2. Hand forged an alg:none with correct claims

```bash
# helper: base64url encode (no padding)
b64url() { openssl base64 -A | tr '+/' '-_' | tr -d '='; }

HDR='{"alg":"none","typ":"JWT"}'
NOW=$(date -u +%s); EXP=$((NOW+3600))
PAY=$(printf '{"sub":"eve@example.com","iss":"go-api-security","aud":"notes-api","iat":%s,"exp":%s}' "$NOW" "$EXP")

TOK_NONE="$(printf %s "$HDR" | b64url).$(printf %s "$PAY" | b64url)."

curl -i -s -H "Authorization: Bearer $TOK_NONE" \
  http://localhost:8080/notes

```
### 3. Tamper a real GOOD token's payload (keep old signature) -> 401

```bash
# get a real (signed) token from the GOOD server
TOK_GOOD=$(curl -s -X POST http://localhost:8080/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"amy@example.com","password":"p@ssw0rd"}' | jq -r .token)

# split into parts
H=$(echo "$TOK_GOOD" | cut -d. -f1)
P=$(echo "$TOK_GOOD" | cut -d. -f2)
S=$(echo "$TOK_GOOD" | cut -d. -f3)

# decode payload, change the subject, re-encode (signature now mismatches)
b64urldec() { python - <<'PY'
import sys,base64, json
s=sys.stdin.read().strip()
pad='='*((4-len(s)%4)%4)
print(base64.urlsafe_b64decode(s+pad).decode())
PY
}
NEWP_JSON=$(echo "$P" | b64urldec | jq '.sub="admin@example.com"')

b64url() { openssl base64 -A | tr '+/' '-_' | tr -d '='; }
NEWP=$(printf %s "$NEWP_JSON" | b64url)

TOK_TAMPERED="$H.$NEWP.$S"

# attempt with tampered payload → rejected
curl -i -s -H "Authorization: Bearer $TOK_TAMPERED" \
  http://localhost:8080/notes

```
