## Good

### 1. Real Decission
```bash
# 1. Real JWT on Good
TOK_GOOD=$(curl -s -X POST http://localhost:8080/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"amy@example.com","password":"p@ssw0rd"}' | jq -r .token)
# 2. Register/rotate secret (protected)
SECRET=$(curl -s -X POST http://localhost:8080/hooks/register \
  -H "Authorization: Bearer $TOK_GOOD" | jq -r .secret)
echo "$SECRET"

# 3. try without JWT -> fails 
curl -i -s -X POST http://localhost:8080/hooks/ingest/amy@example.com \
  -H 'content-type: application/json' \
  -d '{"event":"should-fail"}'


```

### 2. Sign and Send Valid Webhook secret
#### Python
```bash
TS=$(date +%s)
BODY='{"event":"ok","msg":"signed"}'
SIG=$(python - <<PY
import sys,hmac,hashlib,binascii
sec=binascii.unhexlify("$SECRET")
ts="$TS"
body=b'$BODY'
msg=(ts+"\n").encode()+body
print("sha256="+hmac.new(sec,msg,hashlib.sha256).hexdigest())
PY
)

curl -s -X POST http://localhost:8080/hooks/ingest/amy@example.com \
  -H "X-Timestamp: $TS" \
  -H "X-Signature: $SIG" \
  -H 'content-type: application/json' \
  -d "$BODY" | jq .

# verify note exists (JWT required)
curl -s -H "Authorization: Bearer $TOK_GOOD" \
  "http://localhost:8080/notes?q=webhook" | jq .

```

#### OpenSSL

```bash
TS=$(date +%s)
BODY='{"event":"ok","msg":"signed"}'
MSG="$(printf '%s\n%s' "$TS" "$BODY")"
SIG_HEX=$(printf '%s' "$MSG" | openssl dgst -sha256 -mac HMAC -macopt hexkey:"$SECRET" -r | awk '{print $1}')
SIG="sha256=$SIG_HEX"

curl -s -X POST http://localhost:8080/hooks/ingest/amy@example.com \
  -H "X-Timestamp: $TS" \
  -H "X-Signature: $SIG" \
  -H 'content-type: application/json' \
  -d "$BODY" | jq .
```
