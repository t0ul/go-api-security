# A04

## Bad
Duplicate creations
```bash
curl -s -H 'X-User: alice' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-1' \
  -d '{"title":"hello","body":"world"}' \
  http://localhost:8081/notes

curl -s -H 'X-User: alice' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-1' \
  -d '{"title":"hello","body":"world"}' \
  http://localhost:8081/notes

```

## Good No dupelicates

```bash
curl -s -H 'X-User: alice' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-1' \
  -d '{"title":"hello","body":"world"}' \
  http://localhost:8080/notes

curl -i -s -H 'X-User: alice' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-1' \
  -d '{"title":"hello","body":"world"}' \
  http://localhost:8080/notes

```

Replay, the first response, changing the body

```bash
curl -i -s -H 'X-User: alice' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-1' \
  -d '{"title":"DIFFERENT","body":"PAYLOAD"}' \
  http://localhost:8080/notes
```

## Good Rate limiting
Based on IP
```bash
for i in {1..12}; do
  code=$(curl -s -o /dev/null -w "%{http_code}" -H 'X-User: alice' 'http://localhost:8080/notes?q=test');
  printf "%s " "$code"
done; echo

```
