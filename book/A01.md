
# A01 (Broken Access Control)

## Good

### Start secure api

```bash
go run ./cmd/api
# GOOD API on :8080
```

### Make two notes
```bash
curl -s -H "X-User: alice" -H 'content-type: application/json' \
  -d '{"title":"alice t","body":"alice b"}' http://localhost:8080/notes

bob_id=$(curl -s -H "X-User: bob" -H 'content-type: application/json' \
  -d '{"title":"bob t","body":"bob b"}' http://localhost:8080/notes | sed -n 's/.*"id":\([0-9]*\).*/\1/p')
echo "$bob_id"
```

### Vulnerability doesn't work (kinda)
```bash
# read → 404
curl -i -H "X-User: alice" "http://localhost:8080/notes/${bob_id}"

# update → 404
curl -i -X PUT -H "X-User: alice" -H 'content-type: application/json' \
  -d '{"title":"pwned","body":"oops"}' "http://localhost:8080/notes/${bob_id}"

# delete → 404
curl -i -X DELETE -H "X-User: alice" "http://localhost:8080/notes/${bob_id}"

```
