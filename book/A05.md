# A05: Security Misconfigurations

## ACAO

### Bad Access-Control-Allow-Origin: * 

`curl -i -H 'Origin: http://evil.test' http://localhost:8081/demo/dump
`

### Good 

```bash
ALLOWED_ORIGINS='http://good.test' go run ./cmd/api
# in another terminal:
curl -i -H 'Origin: http://good.test' http://localhost:8080/demo/dump
curl -i -H 'Origin: http://evil.test' http://localhost:8080/demo/dump
```
