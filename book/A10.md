# A10

## Good

```bash
curl -i 'http://localhost:8080/demo/ssrf/fetch?url=http://127.0.0.1:8081/debug/pprof/'


```

## Bad

```bash
curl -s 'http://localhost:8081/ssrf/fetch_bad?url=http://127.0.0.1:8081/debug/pprof/' | head -n 5

```

## Takeaway
made the BAD server fetch its own internal pprof endpoint and stream the HTML back to you.
Seeing the <title>/debug/pprof/</title> is a textbook SSRF “gotcha”: an external caller can reach internal admin-only 
surfaces via your app.
